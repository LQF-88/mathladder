# Notices

## Reference material

This project was designed against a privately owned set of printed mathematics
workbooks. **No scanned page, photograph, exercise or answer key from those
workbooks is included in this repository or in the Android package.** Every
question is produced at runtime by original Python generators in
`app/engine/generator.py`.

The level codes 5A through L are used only to describe a learning sequence
(an ordering of topics). They do not reproduce any page, lesson or exercise
from a published workbook.
